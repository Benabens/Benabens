## 🚀 Projects

**[Gaming Addiction Prediction](https://github.com/Benabens/addiction-classifier-numpy)** — ML from scratch, EPFL CS-233 *(team of 3)*<br>
<sub>Python · NumPy · no ML libraries</sub><br>
Predicts gaming-addiction level (3 classes) and score (0–10) from gaming and mental-health data with KNN, logistic/linear regression, K-Means and an MLP with hand-written backpropagation. An inverse-frequency weighted cross-entropy lifted rarest-class recall from **0 to 0.69** and macro-F1 from **0.55 to 0.76** (5-fold CV).
