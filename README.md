## 🚀 Featured projects

**[Cortex](https://github.com/Benabens/cortex)** — AI exam-preparation platform<br>
<sub>Next.js · TypeScript · PostgreSQL · Drizzle · Claude API · LaTeX · Railway</sub><br>
Learns each course's exam format from past papers, weights every topic by how heavily it was examined, schedules spaced revision on the student's weak points, and generates faithful practice exams through a multi-pass LLM pipeline. Answers are accepted only if verified by sandboxed code execution or symbolic checks.

**[Gaming Addiction Prediction](https://github.com/Benabens/addiction-classifier-numpy)** — machine learning from scratch, EPFL CS-233 *(team of 3)*<br>
<sub>Python · NumPy · no ML libraries</sub><br>
KNN, linear and logistic regression, K-Means and an MLP with hand-written backpropagation. An inverse-frequency weighted cross-entropy lifted rarest-class recall from **0 to 0.69** and macro-F1 from **0.55 to 0.76**.

<sub>Java · JavaFX</sub><br>
Finds every Pareto-optimal journey between two Swiss stops with the Connection Scan Algorithm, over real CFF timetables (~258 MB) stored memory-mapped and bit-packed.
